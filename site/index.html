What this page is: an in-browser simulation of the ProductionWatch stack, so you can view the incident workflow without installing anything. It uses the same metric names, alert rules, failure modes and incident lifecycle as the real system: a FastAPI service with Prometheus, Grafana and a Streamlit console, run locally with docker compose up --build. All data is synthetic. This is a learning lab, not a production banking system.
